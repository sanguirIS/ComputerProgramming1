## 📚 Overview

**ComputerProgramming1** is a collection of Java programs, assignments, and exercises
designed to reinforce fundamental computer programming concepts. This repository is
ideal for beginners and students learning Java, or for anyone looking to revisit the
basics.

---

## 🚀 Features

- 100% Java source code
- Covers foundational programming topics:
  - Variables, Data Types, and Operators
  - Control Structures (`if`, `switch`, loops)
  - Functions and Methods
  - Arrays and 2D Arrays
  - String Manipulation
  - Basic Algorithms and Problem Solving

## 🏁 Getting Started

### Prerequisites

- [Java JDK 8+](https://adoptium.net/) (tested with Java 8 through Java 17)
- Git (optional, for cloning)

### Running the Code

Each program is a standalone single-file Java class. To compile and run one, use
`javac` and `java` from its folder. For example:

```sh
# Clone the repository
git clone https://github.com/sanguirIS/ComputerProgramming1.git
cd ComputerProgramming1

# Compile and run the Calculator example
cd "07 Laboratory Exercise 2"
javac Calculator.java
java Calculator
```

The same steps apply to every other `.java` file. Programs that read user input
(e.g. `GrossPayCalculator`, `StudentStats`, `FantasyQuiz`) wait for keyboard input
after they start.
